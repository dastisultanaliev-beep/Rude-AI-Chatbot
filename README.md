# Rude AI Chatbot

A desktop AI chatbot built with Python, CustomTkinter, and an OpenAI-compatible API.

The chatbot communicates with users in a rude and aggressive style while keeping track of the conversation history.

## Features

- AI-powered conversations
- Rude and aggressive assistant personality
- Dark mode interface
- Message history
- Send messages using Enter
- Simple and user-friendly GUI

## Technologies Used

- Python
- CustomTkinter
- OpenAI Python Library
- Bothub API

## Installation

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Install the required libraries:

```bash
pip install customtkinter openai
```

3. Add your API key to the code:

```python
API_KEY = "YOUR_API_KEY"
```

4. Run the application:

```bash
python main.py
```

## How It Works

1. The user enters a message.
2. The application sends the message to the AI API.
3. The AI generates a response.
4. The response appears in the chat window.
5. The conversation history is saved during the current session.
